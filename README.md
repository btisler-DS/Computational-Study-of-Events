# Computational Study of Events

**From Interaction to Observation: A Computational Study of Events, Questions, and Information Formation**

Bruce Tisler · Quantum Inquiry · 2026

This public research repository contains a developing paper and source material for a series of collision-generated computational experiments. The paper examines how an originating event produces a continuing history, how observers encounter that history at different places and times, and how observers may form different informational understandings through inquiry.

**Current manuscript:** [Working draft v0.1.0](paper/v0.1.0/manuscript.md)  
**Versioning policy:** [VERSIONING.md](VERSIONING.md)  
**Experimental series:** [experiments/README.md](experiments/README.md)

The original experiment is a simulated interaction, expressed as `A + B → c`. The generated result c has a traceable computational history. An observer's contact with c is an *encounter*, not proof that a question was asked. The proposed connection between interaction-generated states and question potential is a theoretical interpretation, distinguished from computational observations.

## Research artifacts

The complete archived PDF, images, and animation files are maintained in the research source package and will be linked here once deposited in this repository. A path mentioned here is not a claim that its files have already been uploaded.

## Reproducibility

Each script documents dependencies and command-line arguments. Most runs use pseudorandom seed 14. The experiments include deliberate implementation parameters such as collision cooldowns and a population cap; the visualizations are controlled computational demonstrations.

No claim of peer review or independent scientific validation is made by publication of this repository. See [VERSIONING.md](VERSIONING.md) for how evidence and manuscript changes are recorded.
