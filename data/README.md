# Recorded experiment data

The companion Python programs in [experiments/](../experiments/README.md) generate structured event logs from known initial conditions. [run_summary.csv](run_summary.csv) records the results reported in the manuscript; each row is a single recorded execution, not an average of independent trials.

**The complete event-log JSON files have not yet been deposited here.** They are present in the original frozen research packages. A reproducible source script and event-log writing option exist in the experiment version directories.

Use the original versioned JSON event logs, rather than regenerated or edited substitutes, for source-to-result audits. Any later deposition should include filenames and SHA-256 checksums.
