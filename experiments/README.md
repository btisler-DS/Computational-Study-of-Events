# Experiment Series

Five historical computational experiments support the developing manuscript. Each version should remain individually inspectable rather than being merged into one retrospective implementation.

- `v1/`: original 2D square and generated-ball population.
- `v2/`: single D observer and access-event logging.
- `v3/`: 3D cube projection and 3D collision calculations.
- `v4/`: three distinct observers (D1 violet, D2 orange, D3 white).
- `v5/`: adjustable duration/speed, including the 60-second half-speed example.

The `paper/` version sequence is independent of these experiment numbers. Run outputs and checksums are documented separately in `data/` as deposited.

**Source-of-truth principle:** experiment code and recorded events are authoritative for what was implemented; the manuscript documents those observations and distinguishes the interpretive research question.
